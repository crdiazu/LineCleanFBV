# raw_assets

Material original sin procesar del cliente (fotos, logos, documentos y referencias de diseño) usado como fuente para el sitio LineCleanFBV.

## Estructura

| Carpeta | Contenido |
| --- | --- |
| `logos/` | Logos de la marca en todos los formatos (`.svg`, `.png`, `.jpg`) |
| `fotos/whatsapp/` | Galería recibida por WhatsApp: set 2022 (`WhatsApp Image 2022-08-31*`) y set 2023 (`IMG-20230711-WA*`) + backups `_plaintext_*` |
| `fotos/trabajo-en-altura/` | Serie numerada `trabajo-en-altura-1..29` |
| `fotos/servicios/` | Fotos por tipo de servicio: instalaciones, limpieza de vidrios, cuerdas, líneas de vida, redes, mantención |
| `fotos/equipo/` | Fotos del equipo y profesionales |
| `docs/` | Documentos fuente: planes SEO, calendario de contenido LinkedIn, textos de servicios, notas de altura, propuestas (`.md`, `.docx`, `.json`) |
| `diseno/` | Referencias de diseño: estructura web, wireframes, mockups (incl. generados con Whisk), bocetos SVG, videos demo y guías de diseño (`guidelines/`) |

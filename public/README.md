# LineClean FBV - Previews

Este repositorio contiene los mockups y diseños interactivos para el proyecto Line Clean FBV.

## Opciones de Diseño Incluidas
- **Opción 1: Impacto** - Diseño diagonal dinámico y agresivo con efecto de desvanecimiento (scroll).
- **Opción 2: Dark** - Diseño oscuro, elegante y moderno.
- **Opción 3: Swiss** - Diseño premium y minimalista basado en tipografía.
